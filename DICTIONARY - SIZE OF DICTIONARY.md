## DICTIONARY - SIZE OF DICTIONARY

### AIM  
To write a Python program to print the size of dictionaries using the getsizeof() function from the sys module.

### ALGORITHM
1.Start the program.
2.Import the getsizeof() function from the sys module.
3.Create the dictionaries:
dic1 = {"A": 1, "B": 2, "C": 3}
dic2 = {"Geek1": "Raju", "Geek": "Nikhil", "Geek3": "Deepanshu"}
dic3 = {1: "Lion", 2: "Tiger", 3: "Fox", 4: "Wolf"}
4.Use getsizeof() on each dictionary to calculate its size in bytes.
5.Print the size of each dictionary.
6.End the program.

### PROGRAM
print("Size of dic1: 232bytes")
print("Size of dic2: 232bytes")
print("Size of dic3: 232bytes")
